# CHARGEU base 32A — карта веб-интерфейса (для интеграции в Home Assistant)

Устройство: **CHARGEU base 32A** (chargeu.eu, прошивка ~2015–2018), ESP‑подобный
контроллер. Веб‑морда на `http://192.168.4.1/`. Готовых интеграций для HA нет.

## Ключевые технические факты

- **API нет.** Только HTML, отрендеренный на устройстве. Значения зашиты прямо в
  разметку в шаблоне `<div class=out>МЕТКА<div class=ins>ЗНАЧЕНИЕ</div></div>`.
- Каждая страница содержит `<meta http-equiv="refresh" content="4">` — **полная
  перезагрузка раз в 4 секунды** (для HA это неважно, опрашиваем сами).
- Сырой HTML использует **атрибуты без кавычек** (`class=ins`, `value='$LED 1'`).
  Поэтому парсим по `<div[^>]*>`, не завязываясь на кавычки.
- Все команды управления — это **POST‑формы** (`change`, `change1`, timer‑поля).
  Тело кодируется как в браузере: пробел = `+`, `$` = `%24`
  (напр. `change=%24AMPS+16`).
- **Токены команд не зависят от языка** (`$AMPS`, `$LED`, `$GROUND`, `$LANG`,
  `$AVAIL`, `$TEMPS`) — меняются только подписи и слова‑статусы.

## Страницы

| URL | Назначение | Метод изменения |
|-----|-----------|-----------------|
| `/` | Живая телеметрия | только чтение |
| `/setup` | Ток, язык, заземление, LED, счётчики энергии | POST `change` |
| `/pass` | Блокировка, таймер, разовая сессия, часы | POST `change1` / timer‑поля |
| `/<любой>` | 404: тело `Not found: /...` | — |

## Поля главной страницы `/` (порядок стабилен во всех языках)

Ядро — **8 блоков, всегда присутствуют** и всегда идут последними, в этом порядке:

| # | RU метка | EN метка | UA метка | Значение (пример) |
|---|----------|----------|----------|-------------------|
| 1 | Текущее состояние | Current status | Поточний стан | ЗАБЛОКИРОВАНА |
| 2 | Максимальный ток заряда | Maximum charge current | Максимальний зарядний струм | 10 Ампер |
| 3 | Текущий ток заряда | Current charge current | Поточний зарядний струм | 0.00 Ампер |
| 4 | Текущее напряжение | Current voltage | Поточна напруга | 216 Вольт |
| 5 | Переданная мощность в сессии | Transmitted power in session | Передана потужність в сесії | 2.82 кВт |
| 6 | Длительность сессии | Duration of session | Тривалість сесії | 01:24:35 |
| 7 | Защита от удара током | Protection against electric shock | Захист від ураження струмом | ВКЛЮЧЕНА |
| 8 | Проверка заземления | Ground check | Перевірка заземлення | ВЫКЛЮЧЕНА |

**Опциональные блоки (появляются сверху / при определённых режимах):**
- «Таймер разблокирует станцию через **HH:MM:SS**» — только когда таймер активен и
  станция в режиме таймер‑удержания (блок с фоном `#00ffff`). Тогда блоков 9.
- При активной разовой сессии число блоков доходило до 10 (доп. индикация).

> Вывод для парсинга: индексировать «с конца» ненадёжно (сверху добавляются блоки).
> **Надёжнее всего искать каждое поле по его метке** (с альтернативой RU/EN/UA),
> а числа (ток/напряжение/кВт) не зависят от языка вовсе.

## Слова‑статусы и цвета

| Смысл | RU | EN | UA | Цвет фона `.ins` |
|-------|----|----|----|------------------|
| Заблокирована | ЗАБЛОКИРОВАНА | LOCKED | ЗАБЛОКОВАНА | `#ff0000` (красный) для блокировки |
| Заряжает | ЗАРЯЖАЮ | *(не снято)* | *(не снято)* | `#00ccff` (синий) |
| Вкл (защита/заземление/LED) | ВКЛЮЧЕНА | ENABLED | ВВІМКНЕНО | обычный / зелёный |
| Выкл | ВЫКЛЮЧЕНА | DISABLED | ВИМКНЕНА | `#ff0000` (предупреждение) |

> Слова‑статусы «доступна (не заряжает)» на EN/UA снять не удалось — при разблокировке
> подключённый автомобиль сразу начинал заряд (статус переходил в «ЗАРЯЖАЮ»).
> **Практический сигнал заряда, не зависящий от языка: «текущий ток заряда» > 0.1 А.**

## Полный набор команд (проверено)

Все POST на соответствующий URL, `Content-Type: application/x-www-form-urlencoded`.

### `/setup` (поле `change`)
| Команда | Действие | Диапазон/значения |
|---------|----------|-------------------|
| `$AMPS N` | Макс. ток заряда | N = 6…32 (А) |
| `$LANG X` | Язык интерфейса | X = E / U / R |
| `$GROUND b` | Проверка заземления | b = 0 выкл / 1 вкл |
| `$LED b` | Световая индикация | b = 0 выкл / 1 вкл |

Кнопки на странице всегда показывают **противоположное** текущему состоянию
(заземление выкл → кнопка предлагает `$GROUND 1`). Текущее состояние читается из
`.ins`‑значения рядом с меткой, **не** из значения кнопки.

`/setup` также показывает пожизненные счётчики (обновляются после сессии):
«Энергометр» (напр. 961.06 кВт) и «Переданная мощность всего» (напр. 10789.37 кВт).

### `/pass` (поле `change1`, плюс форма таймера)
| Команда / поля | Действие | Примечания |
|----------------|----------|------------|
| `change1=$AVAIL 0` | Разблокировать (сделать доступной) | с подключённым авто → **сразу начинает заряд** |
| `change1=$AVAIL 1` | Заблокировать (ручная блокировка) | режим без обратного отсчёта таймера |
| `change1=$TEMPS 1` | Включить разовую зарядную сессию | тоже разблокирует и начинает заряд |
| `change1=$TEMPS 0` | Выключить разовую сессию | возвращает блокировку |
| `newtime=YYYY-MM-DDThh:mm:ss` | Синхронизация часов станции | — |
| `timerb=hh:mm&timerbc=1&timere=hh:mm&timerec=1&timeramps=N&timer=b` | Настройка таймера | b = 1 вкл / 0 выкл; timerb=разблокировка, timere=блокировка |

## Три режима «доступности» станции

1. **Таймер‑удержание** — таймер вкл, вне окна [разблокировка…блокировка]. Станция
   заблокирована, на `/` виден блок обратного отсчёта. Это исходное состояние.
2. **Ручная блокировка** (`$AVAIL 1`) — заблокирована, **без** обратного отсчёта.
3. **Доступна** (`$AVAIL 0` или `$TEMPS 1`) — заряжает подключённый автомобиль.

## Важные побочные эффекты (замечено при снятии карты)

- Переключение таймера (off→on) **обнуляет счётчик текущей сессии** (кВт и
  длительность). Пожизненный «Энергометр» при этом не меняется.
- Разблокировка при подключённом авто немедленно запускает реальный заряд.

## Рекомендация по парсингу для HA

- Один `GET /` на интервал → из ответа регулярками по мультиязычным меткам достаём
  все поля. Числа парсим как есть.
- `charging` определять по «текущий ток заряда > 0.1 А» (независимо от языка).
- Для энергодашборда HA использовать пожизненный «Энергометр» с `/setup`
  (`state_class: total_increasing`).
- Управление — через `rest_command` строго повторяя кодировку браузера.
- Рекомендуется зафиксировать один язык станции (проще подписи), но парсер ниже
  понимает RU/EN/UA.
